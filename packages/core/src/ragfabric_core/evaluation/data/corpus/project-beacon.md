# Project Beacon

Project Beacon builds the demand forecasting service sold to customers as the Forecast Pro product.

## Ownership

Project Beacon is owned by the Applied Machine Learning team. Kenji Watanabe is the project sponsor and Sofia Haddad is the technical lead.

## Budget and schedule

The approved budget for Project Beacon is 260,000 US dollars. The first release is planned for November 2026.

## Dependencies

Project Beacon cannot launch until Project Atlas is complete, because the forecasting models train on the new columnar warehouse.

## Risks

Model accuracy on small retailers is below target and needs more training data.
